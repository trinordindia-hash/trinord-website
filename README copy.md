# TRINORD PVT. LTD. Website

Production-ready bilingual corporate website for TRINORD PVT. LTD.

## Development

```bash
cd frontend
npm install
npm run dev
```

In another terminal:

```bash
cd backend
npm install
cp .env.example .env
npm run seed
npm run dev
```

## Features

- English and Marathi language switching with persistent preference
- Responsive public company, business, product, gallery and contact pages
- WhatsApp and phone enquiries
- Contact form connected to the Express API
- JWT-protected administrator dashboard
- Express/Mongoose content and enquiry APIs
- MongoDB Atlas and deployment-ready environment configuration

The supplied 8-page brochure images are stored in `frontend/public/assets/brochure`. Vision, mission and some supporting text are clearly editable placeholders where the brochure did not provide final wording.
